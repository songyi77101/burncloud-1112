# 036 完成四目标真实部署验收与支持门禁

- 任务：在四个目标环境完成运行期 Gitee 运行时下载、缓存复用和真实对话验收，生成可追溯证据。
- 工作区：release（读写）——验收清单/发布门禁；runtime-assets（读写）——资源审计记录。
- 产出：四平台验收报告、包大小/SHA/commit 记录、下载/解压/探测/健康/路由/对话证据和未支持项清单。
- 前置任务：034、035。
- 后置任务：无。
- 验收标准：
  - Windows x64、macOS Intel、macOS Apple Silicon、Ubuntu x64 均在无预装 llama.cpp、无旧缓存的干净环境完成独立记录。
  - 每个平台记录 OS 版本、架构、固定 commit、归档大小/SHA、解压路径、`--version`/`--help`、实际 backend、模型加载、`/health`、`/v1/models`、`/slots`、真实对话和流式响应。
  - 第二个兼容模型证明缓存复用；覆盖取消、停止、服务重启后 interrupted、重新部署和坏包恢复。
  - CUDA 仅验证当前来源返回 `unsupported_backend`，不得以 CPU 结果代替 CUDA 通过。
  - 未完成实机证据的平台保持“未验收”；许可证、依赖、签名和体积证据缺失时不得宣称发行支持。

## 实现内容

本任务不新增生产接口；只执行真实部署黑盒流程并记录证据。所有命令、环境、输出和失败原因必须原样进入后续测试/验收报告。
