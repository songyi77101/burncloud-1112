# 005 登记固定运行包与可信资源库存

## 修改的信息

- 固定 llama.cpp `b8581` 的六项源包；按四个精确 Rust target 选择唯一基础包。Windows/Linux `auto` 仅 CPU，macOS `auto` 依据实际测量选择 Metal 或 CPU；CUDA 12.4 是 Windows 显式选择的独立双包。
- 源包登记与发行锁分开：锁必须由真实归档、动态依赖、许可证及签名/公证证据生成。签名或修正派生包使用实际内嵌摘要与库存；缓存 marker 不作为信任根。
- 记录 Windows 归档的 OpenMP 依赖需单独核对再分发依据，且 VC++ 安装程序必须独立锁定。未取得真实证据时不能发布。

## 修改的文件与文件内位置

- `deploy/runtime/manifest.json`：版本、固定源地址、归档上限、四目标与 CUDA 双包的源身份、服务程序相对路径及最低审计项。
- `deploy/runtime/README.md`：「发行资源准备」约定受控目录、校验与再分发；「发行锁定清单 v1」定义源/内嵌摘要、库存及证据字段；「放行与信任边界」禁止占位证据和以 `ready.json` 放行。
