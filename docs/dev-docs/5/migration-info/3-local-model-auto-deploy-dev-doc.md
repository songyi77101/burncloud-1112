## 与现有实现的差异

1. aria2 引导/轮询改为 reqwest；数字下载 ID 和既有接口保留，旧 GID 不作续传身份。强实体侧车约束连续断点，aria2 分片不能凭长度追加。
2. 新增并登记 SQLite/PostgreSQL 0020 部署任务迁移；本机 owner、单实例锁、部分唯一索引和 CAS 分别处理跨机隔离、在途复用及取消/完成竞争。
3. 运行时按固定包目录从显式配置/缓存/本平台内嵌资源准备。CUDA 双包只按需获取；安全解压、内容库存和原子启用不能退化为检查文件存在。
4. 自动链路与手动路径 Verified 捷径分离；使用确定的短路由 ID 对应完整模型/后端键。补充精确代次停止，不按同名进程清理，不让部署服务的 Ok(Unhealthy) 冒充路由就绪。
5. 客户端目录流程改为任务引用恢复/查询/取消，分别展示两分支；真实对话使用既有 BurnCloud 数据面和原令牌验证，不用模拟回复或虚构本地路径填补接口缺项。
6. 发行由 Windows 扩为四目标，内嵌包与固定上游源包溯源分开：合法签名重封装必须登记派生摘要，不能重签后沿用原 SHA。缺授权、签名、库存或实机证据阻断发行，不以假证据跳过。
